# Python AI Chatbot

A beginner-friendly **Python-based chatbot** designed to simulate a simple conversation with users. The chatbot can respond to greetings, remember the user's name, provide date and time information, answer basic Python-related questions, tell random jokes, and perform basic mathematical calculations.
This project was developed to practice and strengthen fundamental Python programming concepts such as **functions, loops, conditional statements, lists, exception handling, modules, and user input handling**.

# Features
*  Interactive greetings
*  Remembers the user's name during the session
*  Basic conversation
*  Provides basic information about Python
*  Displays the current time
*  Displays the current date
*  Generates random jokes
*  Performs basic calculations
*  Help command to display available features
*  Exit/quit functionality
*  Handles invalid calculator input
